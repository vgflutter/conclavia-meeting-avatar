# Recovered AWS history

These files were recovered from the active studio instance on 22 August 2026.
They preserve useful migration history that had never reached Git, but they are
not the deployment source of truth. The canonical project is
`unreal/ConclaviaStudio`; new changes must be made there and deployed only from
a clean Git commit with `npm run studio:source:deploy`.

Autogenerated Unreal configuration, local backups, tokens, binaries and the
licensed lip-sync plugin were deliberately not recovered into this directory.
